# Мой отчет за День 9 ч.2: cAdvisor - метрики контейнеров и алерты на них

## Что было сделано

### 1. Понял, зачем ещё один экспортер

node_exporter даёт железо (CPU/RAM/диск/сеть хоста), blackbox - «живой ли сайт снаружи». Но оба слепые к тому, что внутри Docker: сколько жрёт конкретный контейнер, кто упал, сколько их. За это отвечает cAdvisor. Ставится на те машины, где живут контейнеры, и отдаёт метрики по каждой cgroup.

### 2. Поставил cAdvisor плейбуком

Ставил сразу контейнером через модуль `community.docker.docker_container` (нужна коллекция `community.docker`).

```yaml
- name: Install cAdvisor.
  hosts: ubuntu_servers:debian_servers
  become: yes
  tasks:
    - name: Run cAdvisor
      community.docker.docker_container:
        name: cadvisor
        image: ghcr.io/google/cadvisor:0.54.0
        state: started
        restart_policy: always
        privileged: true
        published_ports:
          - "8080:8080"
        volumes:
          - /:/rootfs:ro
          - /var/run:/var/run:ro
          - /sys:/sys:ro
          - /var/lib/docker/:/var/lib/docker:ro
          - /dev/disk/:/dev/disk:ro
          - /dev/kmsg:/dev/kmsg
```
