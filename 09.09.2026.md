# Мой отчет за День 7: Multi-stage Dockerfile и HEALTHCHECK

## Что было сделано

### 1. Переделал Dockerfile на multi-stage

До этого бэкенд собирался одной стадией: ставились `gcc` и `libpq-dev` ради компиляции `psycopg2`. Теперь две стадии:

- `builder` ставит зависимости через `pip install --user`
- финальная только python:3.10-slim + скопированные пакеты из builder

```dockerfile
FROM python:3.10-slim AS builder
WORKDIR /build
COPY requirements.txt .
RUN pip install --user -r requirements.txt

FROM python:3.10-slim
WORKDIR /app
COPY --from=builder /root/.local /root/.local
ENV PATH=/root/.local/bin:$PATH
COPY . .
HEALTHCHECK --interval=30s --timeout=3s --retries=3 \
  CMD python -c "import urllib.request; urllib.request.urlopen('http://localhost:8000/health')"
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

Важное открытие: `psycopg2-binary` **не требует компиляции**, поэтому `gcc` и `libpq-dev` выкинул, образ упал до ~232MB.

### 2. Добавил HEALTHCHECK

Контейнер теперь сам проверяет `/health` каждые 30 секунд, Docker помечает его `healthy`. Это видно в `docker ps`.

### 3. Перевёл CI-деплой на Ansible

CI не просто пушил образ в GHCR, а стал после пуша гонять `ansible-playbook`, чтобы кидать код на ноды.

## Итог

Образ стал компактным, контейнер проверяет своё здоровье сам, а CI после сборки сам деплоит проект на машины через Ansible.
