#  День 3 (Часть 2) - Перевод пайплайна в фон через Systemd

##  Что было сделано
Устал от висящих окон Powershell с запущенными по SSH утилитами localtunnel и webhook. Весь стек автоматизации переведен в статус системных служб под управлением `systemd`.

### 1. Перевод утилиты `webhook` в системную службу
Дефолтная служба `webhook.service` была переконфигурирована:
* Конфигурационный файл перенесен в глобальную системную директорию: `/etc/webhook.conf`.
* В `/etc/default/webhook` прописан флаг логирования (`-verbose`).
* Служба добавлена в автозагрузку.

### 2. Создание кастомного сервиса `localtunnel.service`
Написан файл для `systemd`, который выводит локальный порт `9000` наружу в глобальную сеть:
* **Автоматическое восстановление**: Заданы параметры `Restart=always` и `RestartSec=5`, если упадет интернет или оборвется связь с провайдером, операционная система сама поднимет туннель.
* **Фиксация домена**: Через флаг `--subdomain` зарезервировано постоянное статическое имя. Теперь при перезагрузках сервера ссылка не меняется, и конфиги Webhooks на стороне GitHub не ломаются.

Манифест службы `/etc/systemd/system/localtunnel.service`:
```ini
[Unit]
Description=Localtunnel Port 9000 Forwarder
After=network.target webhook.service

[Service]
Type=simple
User=leonlewiz
ExecStart=/usr/bin/npx localtunnel --port 9000 --subdomain уникальное-имя
Restart=always
RestartSec=5
Environment=PATH=/usr/bin:/usr/local/bin:/usr/sbin:/usr/local/sbin

[Install]
WantedBy=multi-user.target
```

##  Траблшутинг-лог: Ошибки и их Решения

### 1. Статус `inactive (dead)` у службы Webhook
* **Проблема**: Служба отказывалась запускаться после изменения настроек.
* **Причина**: Логи через `journalctl` показали ошибку `unmet condition check ConditionPathExists=/etc/webhook.conf`. Пакет `webhook` в Ubuntu жестко требует наличия конфига именно по этому пути.
* **Решение**: Локальный файл `hooks.json` скопирован в `/etc/webhook.conf`, а параметры запуска в `/etc/default/webhook` упрощены до флага `-verbose`. Служба успешно переведена в статус `active (running)`.
