# 🛠️ DevOps Sandbox: Arch Linux & Infrastructure Lab

Этот репозиторий представляет собой персональную лабораторную среду и рабочий лог изучения DevOps-инженерии, системного администрирования Linux и автоматизации инфраструктуры с нуля.

## ⚠️ Дисклеймер проекта

* **Цель проекта:** Исключительно личный интерес, самообразование и практическое освоение инструментов автоматизации.
* **Формат обучения:** Работа ведется по принципу "Learn by Doing" (обучение через практику). Система развернута вручную с нуля для понимания внутренних процессов ОС.
* **ИИ-Ассистент:** В связи отсутствия возможности работы с репетитором/учителем, процесс обучения, код-ревью, разбор ошибок (траблшутинг) и документирование результатов проходят при поддержке ИИ-ассистента **Gemini**. Gemini выступает в роли ментора, помогая находить косяки в конфигах, разбирать системные логи и структурировать полученные знания.

---

## 🏗️ Текущий стек и архитектура

* **OS:** ~~Arch Linux (минимальная ручная сборка) + KDE Plasma в качестве DE.~~ Перешел на Ubuntu Server на второй день.
* **Web-Server:** Nginx (настроен автозапуск через Systemd).
* **CI/CD & Automation:** Локальные Bash-скрипты автоматизации деплоя, интегрированные с Git/GitHub.
