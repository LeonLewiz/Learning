## Разбор ошибок

| Ошибка | Что я вспомнил/понял |
|---|---|
| `Missing sudo password` | `become` требует пароль; Ansible не умеет его вводить → `NOPASSWD` в `sudoers.d` |
| `su` → Auth failed | `su` просит пароль **root**, а в Ubuntu он заблокирован. Нужен `sudo` |
| `cat ~/.vault_pass` → Permission denied | файл создан через `sudo`, стал `root:root`. |
| `203/EXEC` у node_exporter | Нужен `mode: '0755'` |
| `changed` каждый прогон | `unarchive` без `creates` |
| `Failed to import python library / requests` | модуль `docker_container` работает через Python-SDK, которого нет на Debian minimal |
| `network is unreachable` (IPv6) | у ВМ в NAT нет IPv6-маршрута, Docker предпочёл IPv6-адрес реестра. Убрал возможность убунту пользоваться v6 |
