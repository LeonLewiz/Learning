#  Мой отчет за День 3: Связал сайт, Питон и Базу данных в Докере

##  Что было сделано

### 1. Перешел на Docker Compose (Архитектура)
* **Упаковал сайт в образ**: Раньше я просто кидал папку с сайтом в готовый Nginx, а теперь через `Dockerfile` научился собирать свой собственный личный образ, куда код сайта кидается из папки проекта.
* **Поднял три контейнера одной командой**: Написал файл `docker-compose.yml`. Теперь у меня одновременно запускается целая система: мой сайт на Nginx, бэкенд на Питоне и база данных PostgreSQL. Они связываются между собой по внутренней сети Докера.

### 2. Сделал автодеплой по кнопке (GitHub Webhooks)
* **Написал деплой-скрипт (`deploy.sh`)**: Скрипт сам заходит в папку сайта, стирает старые локальные тесты (`git reset --hard`), скачивает свежий код с Гитхаба и пересобирает контейнеры без старого кэша (`--no-cache`), чтобы код точно обновился.
* **Связал Гитхаб со своей виртуалкой**: Поставил на Убунту программу `webhook` и через утилиту `localtunnel` вывел её порт в интернет. Теперь, когда я со своего компа делаю `git push`, Гитхаб сам шлет сигнал на мою виртуалку и запускает деплой-скрипт. Я руками вообще ничего на сервере не ввожу.
* **Спрятал всё в фоновый режим**: Чтобы не держать открытыми окна PowerShell на Windows, я превратил `webhook` и `localtunnel` в фоновые системные службы Убунту (`systemd`). Они теперь работают сами, даже если перезагрузить виртуалку.

### 3. Чему я научился на практике (Траблшутинг)
* **Попробовал SQL**: Залез прямо внутрь работающей базы данных через команду `docker compose exec db psql` и руками пописал запросы: посмотрел таблицы, вывел записи через `SELECT * FROM visits;` и добавил новые строки через `INSERT`.
* **Починил кучу сетевых багов**: 
    1. Разобрался, как развести порты, чтобы не конфликтовать со старым системным Nginx, который стоял на Убунту изначально.
    2. Понял, как открывать порты для Windows через файрвол Убунту (`sudo ufw allow 8000/tcp`).
    3. Исправил ошибку CORS в коде Питона, из-за которой браузер на Windows блокировал запросы от фронтенда к счетчику.
    4. Исправил баг `undefined` в JavaScript, когда Питон присылал число визитов, а фронтенд сначала не мог правильно прочитать тип данных.
