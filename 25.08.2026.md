#  День 3 - GitOps: Docker Compose + Автодеплой через GitHub Webhooks

##  Что было сделано
Проект переведен на автоматизацию. Теперь деплой происходит без участия человека, сервер сам реагирует на изменения в репозитории.

### 1. Подключил Docker Compose
Устал каждый раз писать команды, поэтому использовал манифест docker-compose.yml. Теперь структура написана как код. Контейнер сам перезапускается при сбое (restart: always).
```yaml
services:
  web-site:
    image: my-custom-site:latest
    container_name: my-docker-site
    ports:
      - "9090:80"
    restart: always
```

### 2. Поднята система GitHub Webhooks (GitOps)
* На сервере Ubuntu запустил утилиту `webhook`, которая слушает порт `9000` и по триггеру запускает деплой-скрипт.
* Вывел свою виртуалку VMWare в интернет с помощью `localtunnel`.
* Настроен триггер: любой `git push` в ветку `main` автоматически активирует обновления на сервере.

---

## 🛠️ Траблшутинг-лог: Ошибки и их Решения
* **Проблема**: Конфликт имен при первом запуске Docker Compose.
* **Решение**: Старый контейнер, созданный через `docker run` удалил вручную командой `docker rm -f my-docker-site`.
* 
* **Проблема**: Блокировка `git pull`, не подгружался репозиторий на сервере.
* **Решение**: Сбросил состояние гит через `git reset --hard origin/main`. Вроде заработало.
