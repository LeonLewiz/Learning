# 📈 День 3 (26.08.2026) — Автоматизация деплоя через Dockerfile & скрипт

## 🚀 Что было сделано
Вместо ручного монтирования папок сайт теперь упаковывается внутрь Docker-образа, процесс обновления автоматизирован.

### 1. Написан Dockerfile
Создан манифест для сборки изолированного слоя приложения на базе `nginx:alpine`:
```dockerfile
FROM nginx:alpine
COPY . /usr/share/nginx/html
EXPOSE 80
```

### 2. Разработан скрипт автоматического деплоя (`~/deploy.sh`)
Написан скрипт автоматизации (получается первый пайплайн), который сам забирает код, пересобирает контейнер и перезапускает веб-сервер:

```zsh
#!/bin/zsh

# 1. Переход в рабочую директорию проекта
cd /var/www/html/my-nginx-site

# 2. Синхронизация кода с GitHub репозиторием
git pull origin main

# 3. Сборка нового Docker-образа с тегом latest
docker build -t my-custom-site:latest .

# 4. Удаление старого контейнера (флаг || true предотвращает падение скрипта, если контейнера не существовало)
docker rm -f my-docker-site || true

# 5. Запуск свежего контейнера с пробросом порта 9090 на 80 порт контейнера
docker run -d -p 9090:80 --name my-docker-site my-custom-site:latest

echo "Деплой успешно завершен!"

```

## 🛠️ Траблшутинг-лог: Ошибки и их Решения
*   **Проблема**: Ошибка `ERROR: docker: 'docker buildx build' requires 1 argument` при первой сборке.
*   **Причина**: Забыл указать аргумент (точку `.`) в конце команды `docker build`.
*   **Решение**: Исправлено на `docker build -t my-custom-site:v1 .`. Точка указывает Docker искать `Dockerfile` в текущей папке.
